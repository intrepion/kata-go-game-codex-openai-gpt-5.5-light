# Completion and Deferred Scope

The project is complete only after the root `file://` browser path has been exercised for placement, capture, pass and scoring, undo, and refresh restore. AI play, online play, SGF import and export, handicap, Japanese scoring, and puzzle lessons are explicitly deferred from the MVP.

## Considered Options

- Completion by plausible files existing
- Completion by rule tests only
- Completion by root `file://` interaction evidence
- Completion by user manual playtest

## Consequences

Delivery reports should include evidence from the actual double-clickable root page, not only code checks. Deferred features should not leak into the MVP in partial form unless the project intentionally reopens scope.
