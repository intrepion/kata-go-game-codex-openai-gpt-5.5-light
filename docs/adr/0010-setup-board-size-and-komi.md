# Setup Board Size and Komi

New game setup will allow board size and komi, with a default komi of 6.5. Handicap, first-player selection, and broader ruleset settings are deferred to keep the first setup flow focused and hard to misconfigure.

## Considered Options

- Board size only
- Board size and komi
- Board size, komi, handicap, and first player
- No setup

## Consequences

The MVP must support 9x9, 13x13, and 19x19 boards with editable komi. It should default to 6.5 komi and Black to play first.
