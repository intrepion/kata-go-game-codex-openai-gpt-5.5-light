# Desktop-First with Mobile-Readable MVP

The MVP will optimize board accuracy for desktop while remaining readable and non-broken on mobile. A fully touch-first mobile layout is deferred until the core rules and local play loop are proven.

## Considered Options

- Desktop only
- Mobile readable, with desktop as primary
- Fully touch-first mobile play
- Separate mobile layout

## Consequences

Responsive work must prevent mobile overflow and unusable controls, but the first acceptance path should focus on desktop pointer accuracy and board clarity.
