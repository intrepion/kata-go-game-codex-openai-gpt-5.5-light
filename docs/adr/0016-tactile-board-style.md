# Tactile Board Style

The board should use a tactile wood-board style with black and white stones rather than a tournament diagram, flat UI, or ink-and-paper abstraction. This matches the calm local-play direction while keeping the game recognizable as Go at first glance.

## Considered Options

- Clean tournament diagram
- Tactile wood board with black and white stones
- Modern flat UI
- Ink-and-paper study board

## Consequences

The visual design should prioritize board readability and stone contrast before decoration. The style should support overlays without making liberties, ko warnings, or area ownership hard to read.
