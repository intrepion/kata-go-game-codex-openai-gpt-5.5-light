# MVP Teaching Overlay Scope

The MVP teaching overlay will cover liberties, last move, captured stones, ko warnings, and area ownership after game end. This gives illegal-move explanations and endgame scoring enough visual vocabulary to be understandable without turning the app into a lesson system.

## Considered Options

- Liberties only
- Liberties plus last move and captured stones
- Liberties, last move, captures, ko warning, and area ownership after game end
- No overlays

## Consequences

The interface should explain rule outcomes through board annotations, but it should not add hints, tactical recommendations, or a puzzle lesson engine in the MVP.
